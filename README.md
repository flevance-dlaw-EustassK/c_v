# CineVault

«Информационная система по выбору фильмотеки для домашнего кинотеатра».

Интерактивный frontend-прототип: главная, каталог с фильтрами, страница фильма,
подбор по настроению, личная фильмотека, избранное и профиль. Оценки, избранное
и состояния фильмотеки сохраняются локально в браузере; серверная интеграция не
требуется.

Постеры и фоновые изображения известных фильмов загружаются из TMDB Images CDN.
Если постер недоступен, вместо него показывается локальная заглушка. TMDB API и
серверные запросы не подключены.

## Запуск

```bash
npm install
npm run dev
```

Для проверки типов и production-сборки используйте `npm run typecheck` и
`npm run build`.

## Структура

- `src/app` — приложение, маршруты и место для провайдеров.
- `src/pages` — заготовки страниц React Router.
- `src/components` — повторно используемые компоненты, сгруппированные по назначению; рядом расположены их CSS Modules.
- `src/effects` — отдельные заглушки для будущих киноэффектов и переходов.
- `src/hooks` — начальные хуки для повторно используемой логики.
- `src/services` — заготовки API-клиента, интеграции TMDB и localStorage.
- `src/data` и `src/types` — тестовые фильмы и типы данных.
- `src/styles` и `src/assets` — глобальные стили и статические ресурсы.

Интеграция TMDB и полноценный пользовательский интерфейс пока не реализованы.
