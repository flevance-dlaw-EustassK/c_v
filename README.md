# CineVault

«Информационная система по выбору фильмотеки для домашнего кинотеатра».

Интерактивный frontend-прототип: главная, каталог с фильтрами, страница фильма,
подбор по настроению, личная фильмотека, избранное и профиль. Оценки, избранное
и состояния фильмотеки сохраняются локально в браузере; серверная интеграция не
требуется.

Постеры и фоновые изображения известных фильмов загружаются из TMDB Images CDN.
Если постер недоступен, вместо него показывается локальная заглушка. TMDB API и
серверные запросы не подключены.
